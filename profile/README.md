# WHU Geoscience Café · 地学咖啡馆 ☕🌍

**从一个问题，聊到整个地球。**

欢迎来到 WHU Geoscience Café！这里以地学为起点，围绕地球科学、空间信息与开放研究，分享知识、交流问题、共同探索。

[访问网站](https://whu-geosciencecafe.github.io/) · [浏览仓库](https://github.com/orgs/whu-geosciencecafe/repositories) · [提出话题](https://github.com/whu-geosciencecafe/whu-geosciencecafe.github.io/issues/new/choose)

### 我们关注

- **地球与环境**：地球系统、地表过程与环境变化。
- **空间与观测**：遥感、地理信息与空间分析。
- **数据与开放研究**：代码分享、数据方法与可复现实践。

### 一起参与

一篇论文、一张地图、一段代码，或一个尚无答案的问题，都可以成为交流的开始。

欢迎通过[网站仓库 Issues](https://github.com/whu-geosciencecafe/whu-geosciencecafe.github.io/issues)提出话题或建议，通过 Pull Request 改进公开内容。分享资料时请注明来源，尊重原作者与数据使用约定。

网站正在持续建设，活动与资源将随着内容确认陆续补充。
