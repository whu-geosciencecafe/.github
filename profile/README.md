## 一杯咖啡，连接思想

1983 年，李德仁在斯图加特大学攻读博士学位时，阿克曼教授发放咖啡券，邀请大家边喝咖啡、边讨论学术。2009 年，GeoScience Café 社团正式成立，这份轻松而认真的交流传统在珞珈山下延续。

我们从地球空间信息科学出发，把前沿研究、科普传播与青年成长带到同一张桌前。无论是一个研究问题、一份实践经验，还是一个尚未成形的想法，都可以成为交流的开始。

## 我们在做什么

- **分享前沿学术**：遥感测绘、空间信息、人工智能与时空智能，以及科研写作和研究成果传播。
- **让想法成为作品**：AI Agent 现场开发、Vibe Coding 黑客马拉松与跨学科实践。
- **与世界开放交流**：国际暑期学校、文化交流、学会活动，以及与技术团队和学术组织的合作。
- **把科学讲给更多人听**：气象科普、“大手牵小手”科普讲解与科学精神传播。
- **在同行中成长**：技能培训、校友经验分享，从科研能力到学术与职业方向的探索。

## 一起参与

带来一个好问题，分享一份实践经验，或和我们一起改进公开内容。

- 话题、合作想法与网站建议：[通过 GitHub Issues 交流](https://github.com/whu-geosciencecafe/whu-geosciencecafe.github.io/issues/new)。
- 网站内容与功能改进：[查看源码并提交 Pull Request](https://github.com/whu-geosciencecafe/whu-geosciencecafe.github.io)。
- 公开项目与资料：[浏览组织仓库](https://github.com/orgs/whu-geosciencecafe/repositories)。

网站采用静态页面与结构化 JSON 管理内容，PR 自动构建与检查，更新 `main` 后自动部署。分享资料时请注明来源，遵守原作者与数据的使用约定。
